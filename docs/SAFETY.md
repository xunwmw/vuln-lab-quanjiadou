# 安全与合规边界

本仓库的目的是**在本机练习**，不是提供服务。以下为硬性约束：

1. **只绑定回环地址**：`127.0.0.1`。这意味着一台机器上的靶场，连同一个 Wi-Fi 下的其他设备都访问不到。
2. **不做对外暴露**：不修改监听地址为 `0.0.0.0`，不做端口转发、内网穿透（frp / ngrok / cloudflared）、公网映射。
3. **种子口令不复用**：靶场源码里带的口令只用于本机练习，不得用于任何真实系统。
4. **只碰授权目标**：本仓库中的 PoC 思路仅对本地靶场验证；对任何非授权目标使用都属违规。
5. **非破坏性**：练习时不做数据删除/拖库/写马；验证 RCE 只跑 `id` / `whoami` 这类只读命令。

如果别人想用这些靶场：**让他 clone 本仓库在自己机器上跑**（或起他自己的容器），不要分享你的实例。
