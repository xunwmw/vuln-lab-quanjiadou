# 如何添加一个新靶场

## 目录规范

```
labs/<自建靶场名>/           # 自己写的靶场：app.py（或等价源码）+ README.md
third-party/<名称>/          # 第三方靶场：docker-compose.yml + README.md
```

## README 必须包含的七项

1. **作用**：这个靶场练什么（一句话）
2. **依赖**：运行时要求（Python 版本 / Docker / 镜像名）
3. **启动**：可直接复制的命令
4. **端口**：默认端口与如何改
5. **账号**：练习账号（若含管理员口令，注明"仅本机"）
6. **漏洞清单**：包含哪几类漏洞（自建靶场建议另外提供"去提示化"说明）
7. **复位**：如何恢复干净状态

## 硬性要求

- 监听地址必须是 `127.0.0.1`（compose 里写成 `"127.0.0.1:<port>:<port>"`）
- CI 必须能通过：语法检查 + 冒烟（起服务 → 首页 200 → 复位 200）+ UTF-8 编码守卫
- 不含任何真实凭据、个人路径、内网地址

## 提交

一个靶场一个提交，信息格式：`feat(lab): 新增 <名称>（<作用>）`
