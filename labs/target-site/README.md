# target-site

通用 Web 漏洞靶场（早期版本，默认端口 8080，可传参如 8091）

| 项 | 说明 |
| --- | --- |
| 依赖 | Python 3.8+（**仅标准库，零第三方依赖**） |
| 启动 | `python app.py`（默认端口 8080；也可 `python app.py 8091` 换端口） |
| 复位 | **无 HTTP 复位端点**：停止服务 → 删除同目录下的 `target_site.db`（重启会自动重建种子数据） |
| 监听 | **仅 `127.0.0.1`**（源码硬编码，防误暴露） |

## 作用

练**扫描器扫不到的那类漏洞**：越权访问、支付金额篡改、优惠券并发竞态、密码重置缺陷、会话固定等业务逻辑问题。

## 使用

```bash
cd labs/target-site
python app.py          # 打开 http://127.0.0.1:8080
```

首页列出全部入口；建议先自己找一遍，再对照漏洞清单。

## 演练建议

1. 用两个账号做**水平越权**对照（只用同一账号改 ID 不算）
2. 支付/优惠券类：改价格、改数量、重复核销、并发提交
3. 每次打完立刻复位，保证下一轮环境一致
